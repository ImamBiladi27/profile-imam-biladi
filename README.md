# Imam Biladi - Personal Profile Website

A modern and responsive personal portfolio website built with HTML, CSS, and JavaScript.

## 🚀 Quick Deploy to Vercel

### Method 1: Using Vercel CLI (Recommended)

1. **Install Vercel CLI globally:**
   ```bash
   npm install -g vercel
   ```

2. **Navigate to the project directory:**
   ```bash
   cd /tmp/opencode/profile-imam-biladi
   ```

3. **Deploy to Vercel:**
   ```bash
   vercel deploy --prod
   ```

4. **Follow the prompts:**
   - Login to your Vercel account
   - Accept the defaults or customize as needed
   - Your site will be deployed and you'll get a live URL

### Method 2: Using Vercel Web Interface

1. **Go to [vercel.com](https://vercel.com)** and sign up/login

2. **Click "Add New Project"**

3. **Import your Git repository** (if using GitHub/GitLab/Bitbucket)
   - Or click "Import" and upload the files manually

4. **Configure the project:**
   - Framework Preset: Static
   - Root Directory: Leave as default

5. **Click "Deploy"**

Your site will be live at: `your-project.vercel.app`

## 🛠️ Customization

### Update Personal Information

Edit `index.html`:
- Change your name in the header and hero section
- Update email, location, and phone number
- Modify experience entries in the timeline
- Add your social media links

### Update Skills

Edit the skills section in `index.html`:
- Change skill names and descriptions
- Adjust progress bar widths in `style.css`

### Customize Colors

Edit CSS variables in `style.css`:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    /* ... other colors */
}
```
